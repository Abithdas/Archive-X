Storage & Backup

Cache usage, application data, backup and restore
Archive X cache disk usage
Look-ahead is how far ahead of the playhead Archive X keeps fetching; a longer look-ahead rides out slow stretches but uses more memory and bandwidth. Videos you choose “Keep Current Buffers” for are never expired by the rules above. Connections sets how many parallel Telegram requests playback uses: choose Gentle if you ever see flood-wait messages, Fast only on a very fast link; a change to Fast takes full effect after restarting Archive X.
Cached video ranges are reused; Archive X requests only missing ranges from Telegram. When the size limit is reached, the oldest inactive cache ranges may be removed. Active and upcoming videos are protected.
