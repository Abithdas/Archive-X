## Not verified or not done
- **Windows.** No Windows machine here. WebView2, the NSIS and MSI installers, Defender and SmartScreen behaviour,
  `build.ps1`, and the Windows CI workflow (`desktop.yml`) have **never been run**. Expect fixes on the first run.
- **ffmpeg is not bundled yet.** `desktop/scripts/fetch-ffmpeg.sh` needs a pinned URL and SHA-256 (CI variables).
  The backend already honours `ARCHIVE_X_TOOLS_DIR`.
- **Code signing and auto-update** (plan phase D3): no Authenticode certificate, no updater key, no `latest.json`.
- **Tray / close-to-tray, LAN opt-in setting, data-folder migration for existing installs** (phases D1/D2).
- **Installed size.** 313 MB frozen (181-225 MB `.deb`); PyAV, OpenCV and numpy dominate. Making face clustering an
  optional download is the main lever; Nuitka has not been evaluated.
- **React migration beyond phase 0.** Only the shell, sign-in, and a read-only Library grid exist. Performers,
  studios, photos, player, operations, transfers, settings and all dialogs are still in the classic UI.
- Backend Pydantic response models and generated API types (the TypeScript types are hand-written for now).
- The Outfit font is not bundled in the React app yet (system font fallback).
- macOS builds.

## Video player: audio tracks, subtitles, live English captions
- CC menu in the watch player (Audio / Subtitles columns). Embedded audio tracks are extracted by ffmpeg to a cached AAC file and played in a hidden `<audio>` kept in sync with the muted video.
- Text subtitle tracks (SRT/ASS/mov_text/WebVTT) are converted to WebVTT on demand and cached. Picture subtitles (PGS/VobSub) are listed as unsupported.
- Live captions: optional local engine, `pip install faster-whisper`. Speech is cut into 30 s windows, auto-detected and translated to English (`task="translate"`), cached under `player_cache/captions`. Without the package the menu says how to install it. Default model is "small" (about 460 MB, downloaded on first use; "base"/"tiny" are too weak for Chinese and Japanese). Set `ARCHIVE_X_WHISPER_MODEL=medium` or `large-v3` for better accuracy. The menu has "→ English" and "original language" captions.
- Backend: `playback/tracks.py`, `playback/captions.py`, `web/routes_tracks.py`; tests in `tools/tests/test_media_tracks.py`. Not verified here: real speech recognition and Telegram-streamed sources.

## Player: any format
Order: direct play, then in-browser smart engine (MP4/TS/FLV), then PC conversion to HLS (`/hls/<channel>/<message>/index.m3u8`, H.264/AAC via ffmpeg, played with hls.js and seekable). Each step is tried once, from the position reached. Needs ffmpeg on the PC. Not verified here: actual decoding of the converted stream (sandbox Chromium has no H.264) and Telegram sources.

## Photos home, People, channel pictures, gender
- The app opens on Photos (`/`); the video library is `/videos`.
- Photos has a People row (named people first, then frequent faces; "Is this X?" on unnamed ones). Unnamed face groups also get a third suggestion source: the face in each performer's cached profile picture is embedded during Image Analysis (`performer_face_embeddings`) and compared with the group (SFace cosine >= 0.40). Always a suggestion; the user confirms. Not verified here: real face detection (the models download from GitHub, blocked in the sandbox); the matching was tested with synthetic embeddings.
- Channel pictures show in the video channel row and Transfers pickers; the Telegram photo is now also cached on disk so it appears at launch and offline.
- Performers: default filter Female, plus Trans and All. Gender is set in Edit profile -> Profile details (Unspecified / Female / Male / Trans); provider values like "transgender_female" count as Trans.
